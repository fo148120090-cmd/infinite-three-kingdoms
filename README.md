# 무한 던전 : AI Chronicle

자율 AI 중심의 던전 RPG/RTS 하이브리드 프로토타입입니다.

## 핵심 철학

플레이어가 캐릭터를 조종하는 것이 아니라, 캐릭터가 살아온 방식이 캐릭터의 미래를 결정한다.

플레이어는 파티 구성, 장비, 던전의 다음 경로를 결정합니다. 전투가 시작되면 개별 캐릭터의 이동, 공격 대상, 스킬 사용, 후퇴 여부를 직접 지시하지 않습니다.

## 현재 데모

- 던전 경로 선택
- 자동 실시간 전투
- 캐릭터 AI 성향 10종
- 직업별 행동 패키지
- 장비 랜덤 옵션
- 장비의 AI 성향 보정
- 고유 장비 효과
- 전투 행동 기록
- 경험치와 성향의 점진적 변화
- LocalStorage 저장
- 모바일 대응 UI

### 구현된 AI 성향

공격성 / 용맹 / 신중함 / 생존본능 / 아군보호 / 추적성 / 집중력 / 탐욕 / 호기심 / 협동성

### 몬스터

슬라임, 고블린, 코볼트, 놀, 오크, 리자드맨, 나가, 하피, 우르크, 오거, 아라크네, 세이렌, 다크웜, 데몬의 종족 데이터를 기반으로 확장 가능한 구조를 사용합니다.

멸종과 번식은 시스템에서 제외합니다. 몬스터는 개체 성향, 등급, 레벨, 전투 경험, 장비와 특수 변이에 따라 성장 및 진화합니다.

## 다음 개발 단계

1. 14종 몬스터의 개체 변이/진화 데이터 확장
2. Lv.10 / 20 / 30 자동 전직 시스템
3. 관계도와 기억 시스템
4. Defense 모드
5. Boss Raid 모드
6. 장비 파밍 풀과 고유 장비 확장
7. 던전 이벤트/함정/보스 패턴
8. 전투 연출과 그래픽 에셋
