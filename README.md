# 무한 던전 : AI Chronicle

자율 AI 중심의 던전 RPG/RTS 하이브리드 프로토타입입니다.

## 핵심 철학

플레이어가 캐릭터를 조종하는 것이 아니라, 캐릭터가 살아온 방식이 캐릭터의 미래를 결정한다.

플레이어는 파티 구성, 장비, 던전의 다음 경로를 결정합니다. 전투가 시작되면 개별 캐릭터의 이동, 공격 대상, 스킬 사용, 후퇴 여부를 직접 지시하지 않습니다.

### 구현된 AI 성향

공격성 / 용맹 / 신중함 / 생존본능 / 아군보호 / 추적성 / 집중력 / 탐욕 / 호기심 / 협동성

### 몬스터

슬라임, 고블린, 코볼트, 놀, 오크, 리자드맨, 나가, 하피, 우르크, 오거, 아라크네, 세이렌, 다크웜, 데몬의 종족 데이터를 기반으로 확장 가능한 구조를 사용합니다.

멸종과 번식은 시스템에서 제외합니다. 몬스터는 개체 성향, 등급, 레벨, 전투 경험, 장비와 특수 변이에 따라 성장 및 진화합니다. 보스는 이전 레이드의 전투 경험을 저장하지 않으며, 매 레이드마다 새 전투 개체로 시작합니다.

게임의 최종 목표는 동굴을 계속 돌파해 6F 이후 나타나는 악의 동굴을 찾는 것입니다. 악의 동굴은 마계와 연결된 세계의 구멍이며, 최종 전투에서 강력한 수문장을 쓰러뜨린 뒤 세계의 구멍을 봉인합니다. 완료한 층은 반복 도전할 수 있고 반복 보상은 단계적으로 감소하며, 재도전 중 일부에는 정예 몬스터 무리가 등장합니다.

영웅은 전투 성과를 연대기로 기록합니다. 업적과 칭호는 실제 공격력/방어력/HP/속도 보너스로 전투 계산에 반영되며, 현재 기분·상태·시스템 평가도 파티 화면에 표시됩니다. 기초 직업 5종은 모집소에서 지속적으로 확보할 수 있고, 직업별 코스튬은 일반/희귀/유니크 테마로 구성됩니다.
