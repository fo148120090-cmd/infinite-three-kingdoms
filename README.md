# 무한삼국지: 천탑전기

《무한삼국지: 천탑전기》 MVP 프로토타입.

## 현재 구현
- React + TypeScript + Vite
- 메인 / 천탑 / 장수 / 전투 / 편성 / 소환 / 장비 화면
- 10명 장수 데이터 및 ★1~★6 성장
- 장수 조각 / 돌파 시스템
- 5인 편성 및 순서 관리
- TS 스킨 해금 시스템
- 장수별 전용장비 +20 강화 / 옵션 / 희귀도
- 전용장비 소환
- 10×10 격자 기반 수동 턴제 전투
- 실제 이동력 / 지형 이동비용
- 기본 공격 / 장수별 고유 스킬 / 상태이상
- 적 자동전투 AI 턴
- 천탑 1~100층 / 10층 단위 보스 구조
- 층별 난이도 scaling / 보스 modifier / 보상 scaling
- LocalStorage 진행 저장
- 모바일 반응형 UI

### 전투 설계 원칙
- 궁극기 시스템은 사용하지 않음
- 분노(Rage) 게이지는 사용하지 않음
- 전투의 핵심은 이동, 일반공격, 고유 스킬, 대기와 지형 활용

## 개발 로드맵
1. 전투 연출 및 장수 고유 패시브
2. 보스 전용 스킬 / 패턴 고도화
3. 천탑 층별 보상 선택지
4. 10→50→100 장수 확장
5. 장수 인연 / 진형 보너스
6. 스토리 챕터 / 개인 장수 스토리
7. 그래픽 에셋 및 스킬 연출

## 실행
```bash
npm install
npm run dev
```
