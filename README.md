# 무한삼국지: 천탑전기

《무한삼국지: 천탑전기》 MVP 프로토타입.

## 현재 구현
- React + TypeScript + Vite
- 메인 / 천탑 / 장수 / 전투 화면
- 10명 장수 데이터
- 7×6 격자 턴제 전투
- 이동 대신 MVP 공격/턴 루프를 우선 구현
- 적 자동 반격 AI
- 천탑 층 진행 및 보상 기반 확장 구조
- LocalStorage 진행 저장
- 모바일 반응형 UI

## 실행
```bash
npm install
npm run dev
```
