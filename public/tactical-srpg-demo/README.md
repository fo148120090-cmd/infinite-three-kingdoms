# 전술전기 · 첫 전투 데모

삼국지 조조전 온라인 계열의 전술 SRPG 감각을 참고한 별도 프로토타입 영역입니다.

## 1차 데모 범위
- 10×8 격자 전투
- 아군 5명 출전
- 적 9명
- 플레이어 직접 이동/공격/스킬 선택
- 아군 턴 / 적군 턴
- 이동 가능 칸 표시
- 공격 가능 칸 표시
- HP / 공격 / 방어 / 이동력 / 사거리
- 평지 / 도로 / 숲 / 수로
- 승리/패배 조건
- 전투 로그
- 재시작
- 12종 이상으로 확장 가능한 병종 데이터 구조

## 의도적으로 제외
- 고저차
- 화공
- 사기

## 현재 전투 시스템
1. 병종 상성: 병종별 강점/약점에 따른 공격 보정
2. 반격: 방어 유닛의 사거리 안이면 피격 후 반격
3. 협공: 공격 대상 주변의 아군 병종이 추가 공격
4. 지원공격: 지원 사거리를 가진 궁병/책략가 등이 추가 피해
5. 스킬 범위: 스킬별 사거리와 범위 공격(AOE) 표시 및 대상 지정
6. 지형 보정: 숲 방어 +4, 숲 이동비용 2, 도로 공격 +2, 수로 이동 불가
7. 승리조건 다양화: 전멸전 / 지휘관 격파 / 거점 점령 / 5라운드 생존
