# 전술전기 · 첫 전투 데모

삼국지 조조전 온라인 계열의 전술 SRPG 감각을 참고한 별도 프로토타입 영역입니다.

## 1차 데모 범위
- 10×8 격자 전투
- 아군 5명 출전
- 적 9명
- 플레이어 직접 이동/공격/스킬 선택
- 아군 턴 / 적군 턴
- 이동 가능 칸 표시
- 공격 가능 칸 표시
- HP / 공격 / 방어 / 이동력 / 사거리
- 평지 / 도로 / 숲 / 수로
- 승리/패배 조건
- 전투 로그
- 재시작
- 12종 이상으로 확장 가능한 병종 데이터 구조

## 의도적으로 제외
- 고저차
- 화공
- 사기

## 향후 확장
1. 병종 상성 및 무기 계통
2. 협공/반격/지원
3. 지형 효과 정교화
4. 전장 이벤트와 증원
5. 스킬/상태이상
6. 경험치/레벨업
7. 장비/전직
8. 스토리 전투와 전투 조건

## 에셋
- `assets/units/`: 아군 5종 + 적군 8종 전술 유닛 SVG 스프라이트
- `assets/tiles/`: 평지/도로/숲/수로 지형 타일 SVG
- 브라우저에서 별도 외부 에셋 서버 없이 직접 로드

## 파일
- index.html: 데모 진입점
- style.css: 전투 UI와 에셋 렌더링
- game.js: 전투 데이터, 턴 처리, 이동, 공격, 적 AI
